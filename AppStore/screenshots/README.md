# Screenshot App Store — piano 1.2

Regola: solo schermate **reali** dell’app, nessuno screenshot inventato,
ritoccato o con dati non ottenibili. Due set previsti: `it-IT/` e `en-GB/`
(quest’ultimo da catturare con l’app in inglese). Verticale, senza trasparenza.

Per iPhone usare una dimensione accettata da Apple per display da 6,9", ad
esempio `1320 × 2868` da iPhone 16 Pro Max oppure `1290 × 2796` da iPhone
15 Pro Max/16 Plus. Da uno a dieci screenshot per set sono ammessi.

## Da catturare per la 1.2 (stesso schema numerico, poi copia nel set `en-GB/`)

6. Live Activity su schermata di blocco e Dynamic Island durante una
   rigenerazione: avviare il Laboratorio DPF → “Esegui ciclo completo
   (8 secondi)”, bloccare lo schermo e catturare durante la fase attiva
   (banner arancione, avanzamento, temperatura).
7. Compatibilità adattatore BLE: dashboard connessa tramite ELM327 Bluetooth
   LE (adattatore reale; in alternativa marcare esplicitamente la simulazione
   come tale, senza spacciarla per una connessione reale).

Dopo la cattura rinominare con lo stesso schema numerico e copiare nel set
`en-GB/` con l’app impostata in inglese.
